## Open-source projects

- [PixelPair](https://github.com/ddunddun-labs/PixelPair)  
  A local-first pixel art editor where you and an MCP-capable coding agent can work on the same live canvas.

- [RepoSide](https://github.com/ddunddun-labs/RepoSide)  
  A lightweight Windows companion for GitHub Desktop with repository-aware file trees and persistent terminal sessions.

- [README Demo Skill](https://github.com/ddunddun-labs/readme-demo-skill)  
  A Codex skill for creating reproducible README demos using Playwright, VHS, and FFmpeg.

- [Code Printer](https://github.com/ddunddun-labs/code-printer)  
  A browser-based tool for printing and exporting source code with clean A4 layouts.
